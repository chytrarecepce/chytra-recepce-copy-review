# Chytrá recepce — редактор текстов

Отдельный проект для проверки и выбора русских и чешских текстов главной страницы. Он не связан с кодом основного сайта и не изменяет репозиторий `chytrarecepce/website`.

## Как работать

1. Откройте `index.html` в браузере.
2. Просматривайте все блоки страницы подряд.
3. Для каждой строки выберите отдельный вариант.
4. При необходимости впишите собственный RU/CS-текст и комментарий.
5. Используйте фильтры «Все», «Не проверены» и «Проверены».
6. Нажмите «Скопировать результат» и вставьте результат в чат с Codex либо скачайте Markdown-файл.

Выбор сохраняется в браузере этого устройства. Чтобы перенести решения на другое устройство или вернуть их в Codex, используйте экспорт результата.

## Приватность

Репозиторий следует создавать приватным. Не включайте обычный GitHub Pages: опубликованная Pages-страница может быть общедоступной, даже если исходный репозиторий приватный.

## Файлы

- `index.html` — автономный адаптивный редактор, работающий без сборки и зависимостей.
- `README.md` — инструкция.
